Classless.css is one small CSS file, which defines few but great styles for basic HTML5 tags plus very few classes for grid, cards and spacing. Nothing more. Nothing less. 

**Demo:** at [classless.de](http://classless.de/)

With the basic tag styling, Classless provides a solid appearance for simple article pages without any classes. If you need more fancy features such as grid or cards – which are infeasible with basic HTML5 – we provide a few Bootstrap compatible classes.

#### Features

- **Small.** Only 400 lines of pure CSS3 for themes, grid, navigation bar, cards and more.
- **Single File.** Everything in one file, no dependencies¹, no JavaScript required.
- **Modular.** Don't need all features? The CSS file is structured into feature groups, simply delete what you don't need².
- **Responsive.** We use media queries, `em/rem` units, and smart overflows for tables and code.
- **Bootstrap Compatible.** The few classes use the same names as Bootstrap.
